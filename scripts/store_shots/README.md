# App Store スクリーンショットの作り方

素のキャプチャを `スナップショット/raw/<iphone|ipad>/` に置いて、

```bash
python scripts/store_shots/compose.py
```

を走らせると、`スナップショット/store/<iphone|ipad>/` に見出し付きの画像ができる。
出力サイズは iPhone 6.9" (1320x2868) と iPad 13" (2064x2752)。
キャプチャした端末のサイズは問わない (枠の中に縮めて置く)。

どの画面を・どの見出しで出すかは `shots.json`。`src` のファイルが無い行は飛ばす。

## 撮るもの (shots.json の順)

| # | name | 開く画面 | 状態 |
|---|---|---|---|
| 1 | timeline | ホーム (統合タイムライン) | X と Bluesky の投稿が混ざって見えている。画像付きが 1 つあるとよい |
| 2 | accounts | アカウント一覧 | 4〜5 件、X と Bluesky が混ざっている (既存のキャプチャで可) |
| 3 | compose | 投稿画面 | 本文を入れ、アカウントを 1 つ選び、画像を 1 枚付けた状態 |
| 4 | engage | 投稿詳細 + いいねのアカウント選択シート | 既存のキャプチャで可 |
| 5 | notifications | 通知 (すべて) | フォロー・いいね・リプライが混ざっている |
| 6 | follow | フォロー/フォロワーの対象画面 | 数字のカードが埋まり、履歴が数件ある |
| 7 | blockscan | つながり調査の結果画面 | 完了した調査で、ブロック・ミュートの件数が出ている |
| 8 | customize | 設定 (外観) | 既存のキャプチャで可 |

iPad は 1・2・5・6・8 の 5 枚。

## 撮るときの約束

- **他人が映らないようにする。** 自分のテストアカウント同士で相互フォローし、投稿・いいね・リプライを作ってから撮る。
  他人の名前が混ざる画面は「匿名モード」で撮るか、使わない。
- ステータスバーは Wi-Fi・満充電の状態で。時刻は気にしなくてよい (枠の中では小さい)。
- ライトテーマではなくダークテーマで撮る。背景がダークなので、ライトだと浮く。
- 読み込み中の輪・空のリスト・「新しい投稿」のバナーが映っていないか確認する。
- iPhone はどの機種でもよい。iPad は 11 インチ級で撮れば 13 インチ枠に収まる。

## 見出しを直す

`shots.json` の `title` (2 行まで。`\n` で折る) と `subtitle` (1 行) を書き換えて走らせ直す。
句読点は行頭に来ないよう自動でぶら下げる。
